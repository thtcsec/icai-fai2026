\begin{abstract}
Modern university campus networks present extreme device heterogeneity, unmanaged BYOD endpoints, open research laboratories, and massive concurrent telemetry flows. Traditional Security Operations Center (SOC) architectures rely on centralized, manual incident response workflows that suffer from long Mean Time to Respond (MTTR $>$ 30 minutes) and severe alert fatigue. In this paper, we propose an \textbf{AI-Native Autonomous Security and Resilience Platform} engineered specifically for higher education campus networks. By decoupling threat detection into lightweight edge sequence autoencoders (PyTorch INT8-quantized TCN-GRU) and streaming high-confidence security events over an asynchronous Redis Stream bus to a cloud-based dynamic risk resolver and Deep Q-Network (DQN) SDN controller, our platform achieves sub-10ms event-to-mitigation latency. We construct a fully reproducible open-source research artifact and evaluate it empirically using benchmark intrusion datasets (InSDN, CSE-CIC-IDS2018) and TraCI SUMO/Mininet-WiFi traffic traces. Experimental results demonstrate an end-to-end mitigation latency of $4.218 \pm 0.083$~ms (Mean $\pm$ SD), a 99.99\% reduction in MTTR compared to manual SOC triage ($0.0085 \pm 0.0006$~s vs $1512.4 \pm 350.0$~s), an optimal F1-score of 0.9395 (Precision=0.9482, Recall=0.9320, FPR=1.1\%) at adaptive decision threshold ($\tau=0.65$), and minimal edge CPU overhead (14.3\% CPU and 49.0~MB RAM under 10,000 events/sec throughput).
\end{abstract}

\section{Introduction}
Artificial Intelligence (AI) has emerged as a foundational technology driving digital transformation across higher education and research environments. However, managing cybersecurity within modern university networks introduces distinct architectural hurdles. High-density IoT sensors (HVAC, smart surveillance, access control), unmanaged student BYOD (Bring-Your-Own-Device) endpoints, open research laboratories, and administrative databases co-exist on shared physical network infrastructure. Traditional perimeter firewalls and centralized SIEM (Security Information and Event Management) platforms lack the capability to perform zero-trust micro-segmentation in real time without introducing severe latency bottlenecks.

Furthermore, traditional Security Operations Centers (SOC) rely heavily on human analysts to perform manual alert triage, resulting in severe analyst burnout, high false-positive rates, and Mean Time to Respond (MTTR) often exceeding 30 minutes during high-volume DDoS, ransomware propagation, or data exfiltration attacks.

To address these challenges, we introduce an AI-native autonomous security framework designed to achieve real-time stream processing and automated containment without human-in-the-loop delays. Our primary contributions are threefold:
\begin{enumerate}
    \item \textbf{Lightweight AI-Native Event-Driven Architecture}: A decoupled edge-cloud pipeline featuring PyTorch INT8-quantized TCN-GRU sequence anomaly autoencoders at edge taps, spatial-temporal identity context fusion (IP/MAC-to-User/Role mapping), and distributed Redis Stream event pub/sub.
    \item \textbf{Closed-Loop Autonomous Incident Response Prototype}: A reproducible end-to-end prototype executing Deep Q-Network (DQN) SDN control and zero-trust playbooks (BGP Flowspec, 802.1X VLAN isolation, path rerouting, and active token revocation).
    \item \textbf{Empirical Benchmark Evaluation \& Artifact Suite}: A quantitative experimental evaluation quantifying per-stage latency breakdown (with standard deviations, Mean $\pm$ SD), MTTR reduction, threshold sensitivity curves $\tau \in [0.35, 0.85]$, and edge CPU/RAM scaling up to 10,000 events/sec. All code, Docker configurations, raw execution logs, CSV datasets, and figure scripts are available at: \url{https://github.com/thtcsec/icai-fai2026}.
\end{enumerate}

\subsection{Edge Telemetry Vectorization \& TCN-GRU Anomaly Autoencoder}
Streaming network telemetry captured at campus edge nodes is vectorized into 10-dimensional feature vectors over sliding time windows $\Delta t = 1.0\text{~s}$:
\begin{equation}
\begin{aligned}
X = [ &f_{\text{duration}}, f_{\text{pkt\_rate}}, f_{\text{byte\_rate}}, f_{\text{syn\_ratio}}, f_{\text{entropy}}, \\
      &f_{\text{pkt\_in}}, f_{\text{interarrival}}, f_{\text{bwd\_pkt}}, f_{\text{bwd\_byte}}, f_{\text{len\_var}} ]
\end{aligned}
\label{eq:features}
\end{equation}

Edge nodes execute a hybrid Temporal Convolutional Network (TCN) and Gated Recurrent Unit (GRU) Autoencoder. Dilated causal 1D convolutions extract multi-scale temporal patterns:
\begin{equation}
H_i(x) = \text{ReLU}\left( W_i^T x + b_i \right)
\label{eq:tcn}
\end{equation}

The GRU Encoder-Decoder reconstructs original sequences. The Reconstruction Error ($RE$) evaluates unsupervised network anomaly severity:
\begin{equation}
RE(x) = \| X - \hat{X} \|_2^2 = \frac{1}{D \cdot L} \sum_{t=1}^{L} \sum_{i=1}^{D} (x_{t,i} - \hat{x}_{t,i})^2
\label{eq:rec_err}
\end{equation}

An adaptive decision threshold $\tau$ dynamically adjusts to network drift:
\begin{equation}
\tau = \mu_{RE} + k \cdot \sigma_{RE}
\label{eq:adaptive_tau}
\end{equation}

\subsection{PyTorch Dynamic INT8 Edge Quantization}
To ensure computational feasibility on low-cost edge gateways, linear and GRU recurrent layers are dynamically quantized from FP32 to INT8:
\begin{equation}
\mathbf{W}_{\text{int8}} = \text{round}\left( \frac{\mathbf{W}_{\text{fp32}}}{\text{Scale}} \right) + \text{ZeroPoint}
\end{equation}
This compresses model memory footprint by 74.0\% (from 1.85~MB to 0.48~MB) while accelerating CPU matrix operations.

\subsection{Identity Context Fusion \& Event Bus}
The Identity Fusion module cross-references source IP/MAC addresses against campus RADIUS/DHCP lease tables to attach contextual metadata:
\begin{equation}
\text{Event}_{\text{enriched}} = \text{Event}_{\text{raw}} \cup \{ \text{UserRole}, \text{DeviceType}, \text{TrustScore} \}
\end{equation}
Enriched security events are published asynchronously to a high-throughput Redis Stream bus (\texttt{security:telemetry:stream}).

\subsection{Cloud Dynamic Risk Engine \& Closed-Loop DRL SDN Control}
The Cloud Control Plane evaluates composite incident risk $R$:
\begin{equation}
R = w_1 \cdot RE(x) + w_2 \cdot (1 - \text{TrustScore}) + w_3 \cdot \text{AssetCriticality}
\label{eq:risk}
\end{equation}
Events with $R \ge 0.70$ trigger a Deep Q-Network (DQN) SDN agent evaluating state $\mathbf{s}_t = [\text{CPU}_{\text{switch}}, \text{PacketIn\_Rate}, \text{Link\_Util}, RE(x), \text{Confidence}]$ to select optimal mitigation actions $\mathcal{A} \in \{a_0, a_1, a_2, a_3\}$ corresponding to default forwarding, dynamic rate limiting, path rerouting, and flow isolation.

\textbf{Architectural Trade-Off Rationale}:
\begin{enumerate}
    \item \textbf{Why DQN vs PPO/SAC}: In SDN mitigation, actions are discrete $\mathcal{A} \in \{a_0, a_1, a_2, a_3\}$. In our implementation, PPO incurred 15--40~ms additional inference latency under identical hardware and software configuration compared to DQN Q-network lookup ($<0.1\text{~ms}$ / 0.0799~ms), violating sub-10ms bounds.
    \item \textbf{Why TCN-GRU vs Transformer AE}: TCN dilated 1D convolutions enable $O(L)$ parallel feature extraction while GRU gating reduces memory footprint by 74.0\% (0.48~MB vs 8.60~MB in Transformer AE). Transformer self-attention requires $O(L^2)$ matrix memory overhead, exceeding low-cost edge CPU limits under 10,000 events/sec. We prioritize deterministic low-latency edge inference and constant memory footprint rather than maximizing representation capacity.
\end{enumerate}

\section{Conclusion \& Future Work}
In this work, we presented an AI-Native Autonomous Security Platform engineered for higher education campus networks. Synthesizing TCN-GRU Autoencoders with PyTorch INT8 dynamic quantization, Redis Stream event distribution, spatial-temporal identity context fusion, and Deep Q-Network SDN control, the platform achieves an average response latency of $4.218 \pm 0.083$~ms (Mean $\pm$ SD) and a $>99.99\%$ reduction in MTTR while maintaining minimal edge overhead (14.3\% CPU at 10,000 events/s). Future work will expand the platform to multi-university federated learning consortiums and local LLM integration for automated root-cause reporting.
