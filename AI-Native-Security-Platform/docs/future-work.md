# Future Work & Research Roadmap

## 1. Multi-University Federated Learning
Future iterations aim to deploy Privacy-Preserving Federated Learning (FL) across participating university consortiums (e.g., CMC University, Steinbeis University, Tsinghua University). This will enable edge nodes to train collaborative anomaly models without exposing sensitive campus IP addresses or student telemetry.

## 2. LLM-Assisted Root Cause Triage
Integrating lightweight local LLMs (e.g., Llama 3 8B or Mistral 7B quantized) into the Cloud Policy Engine to generate natural-language incident summaries, threat intelligence mapping, and human-in-the-loop audit logs for security analysts.

## 3. Zero-Trust SDN Micro-segmentation
Extending SOAR playbooks from perimeter IP blocking to dynamic Software-Defined Networking (SDN) OpenFlow rules, enforcing instant micro-segmentation down to individual virtual switch ports.
